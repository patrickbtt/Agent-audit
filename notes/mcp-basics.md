MCP = a standard way to connect an AI to tools (email, files, database…).
Server = the program that offers the tools.
Client = the AI app that uses them.
Tool = an action the AI can do, like “read_file”.
Danger = the AI trusts tool descriptions, so a malicious description can manipulate it.
